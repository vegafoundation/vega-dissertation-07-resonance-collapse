## Definition

Resonance Collapse is the conceptual model of decision-making as the collapse
of superimposed meaning states into a single coherent outcome.

## Core Concept

Decision is NOT:
- Ranking scores
- Maximum selection
- Optimization result

Decision IS:
- State collapse from superposition
- Resonance-triggered transition
- Emergent coherence

## Mathematical Metaphor

Inspired by quantum state collapse (Copenhagen interpretation).
Applied to meaning states in classical computation.
No quantum physics claims.
